THE CUTTING ROOM — UNOFFICIAL WEBSITE CONCEPT

Preview status:
This is an independent demonstration concept, not an authorized or official salon website.
Obtain the owner's approval before publishing as the business's official site or connecting a domain.

Contents:
- index.html: complete responsive one-page site
- styles.css: visual system and responsive layouts
- script.js: mobile navigation, reveal animations and current footer year
- assets/: photographs supplied for this project
- favicon.svg and og-image.svg: brand assets

To preview locally, open index.html in a modern browser.
The page uses Google Fonts over the internet. The site itself is static and can be hosted on Cloudflare Pages, Netlify, GitHub Pages, or similar static hosting.

Known content limitation:
Full opening hours and appointment booking URL were not supplied, so neither is invented. The page directs visitors to call for appointment and hours information.
